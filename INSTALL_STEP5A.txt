Installation
------------
1. Confirm branch:

git branch --show-current

Recommended:
feature/review-engine

2. Copy R/review_annotation.R into the package R directory.

3. Copy tests/testthat/test-review-annotation.R into tests/testthat.

4. Run in RStudio:

devtools::document()
devtools::test(filter = "review", reporter = "summary")
devtools::load_all()

5. Run on the current Seurat object:

review_result <- review_annotation(
  seurat_object,
  output_dir = "annotation_review"
)

review_result
review_result$manifest

annotation_review/
