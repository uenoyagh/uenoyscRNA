# uenoy scRNAseq Framework v2.6 — Cluster Fraction Transition

## Files to install
Copy these files into the existing framework root:

- `analysis/06_cluster_fraction_transition.R`
- `R/cluster_fraction_engine.R`
- `R/cluster_fraction_plot.R`
- `config/cluster_fraction_config.R`

Framework root assumed by the script:

`/Users/uenoya/Projects/uenoyscRNA`

## Default dataset

`Mouse_MASH_Mphi_RDS`

Change `cluster_fraction_analysis_target` in
`config/cluster_fraction_config.R` to analyze another one of the four active datasets.

## Run

```r
source("/Users/uenoya/Projects/uenoyscRNA/analysis/06_cluster_fraction_transition.R")
```

## Output

The module uses the existing framework's `get_result_dir()` and writes under:

`<result_dir>/cluster_fraction/cluster_fraction_transition_v2.6/`

Subdirectories:

1. `01_line_total_fraction`
2. `02_line_within_annotation`
3. `03_line_cell_count`
4. `04_stacked_cluster`
5. `05_stacked_annotation`
6. `06_tables`

Both PDF and 300-dpi PNG are generated by default. CSV tables include zero-valued
condition × annotation × cluster combinations.

## Metadata detection

The module attempts to detect:

- cluster
- annotation
- condition
- sample

For reproducibility, set explicit override column names in
`config/cluster_fraction_config.R` after confirming the correct metadata columns.

If no condition column is found, condition is inferred from sample labels using the
regex map in the config file. The default order is:

`STD → CDAHFD → Sham → Tx`

## Overwrite behavior

The module reuses `overwrite_existing` from `config/local_config.R`.
Set it to `TRUE` while revising plots.

## Scope and validation note

This module was prepared from the supplied framework scripts and example figure,
but it has not been executed against the user's local RDS objects. The first run
should therefore be treated as validation. Inspect the generated
`*_resolved_metadata_columns.csv` and fraction tables before interpreting plots.
